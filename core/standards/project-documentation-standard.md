# Project Documentation Standard

Every project created from this AI platform must include the following
documentation.

## project.md

Purpose:

-   Project overview
-   Business goals
-   Core features
-   Business rules
-   External integrations

## architecture.md

Purpose:

-   High-level architecture
-   Major components
-   Directory structure
-   Data flow
-   Key services
-   External systems

## decisions.md

Purpose:

Record significant architectural and technical decisions.

Each entry should include:

-   Decision
-   Reason
-   Date
-   Impact

## roadmap.md

Purpose:

-   Planned features
-   Technical debt
-   Future enhancements
-   Deferred work

## Maintenance

Documentation is a living part of the project.

Whenever implementation changes, review these documents and update them
as required.

Documentation must never drift from the implementation.
