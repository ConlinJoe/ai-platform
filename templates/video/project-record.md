# Video production

This project opted into the harness video-production capability.

The harness owns the shared workflow and renderer. This project owns
briefs, brand decisions, source media, scene specs, custom animation,
and rendered files.

Local rendering does not spend Scenario credits. It does not authorize
publication, upload, or paid generation.

Campaigns live in `video/campaigns/`. One campaign must not reuse
another campaign's brand file or assets.

Canonical workflow:
`docs/contracts/features/video-production.md` in the AI Platform clone.
